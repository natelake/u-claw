🦞 U-Claw Guide

Portable AI workspace · 3 steps to start
Quick start
Step 1: Start the service
Double-click the launcher for your system:

Windows: double-click Windows-Start.bat
Mac: double-click Mac-Start.command
Step 2: Configure an AI model
First launch opens the config page:
1. Pick an AI model (DeepSeek is a cheap coding default)
2. Enter an API Key from the provider site
3. Click Save
Step 3: Start chatting
After saving, the browser opens the chat UI
Address: http://127.0.0.1:18789
You can chat with the assistant now.

✅ All config and chat history stay on the USB in data/ and are shared across Mac and Windows.

Suggested models
🔥 DeepSeek Great for coding, inexpensive
📄 Kimi Long-document specialist
🆓 Qwen Large free tier
🌟 Claude Strongest general understanding
Need help?
💡 Run the diagnostic tool

If start failed, double-click the diagnostic tool:
Windows: Windows-Diagnose.bat
Mac: Mac-Diagnose.command
