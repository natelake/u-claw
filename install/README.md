# U-Claw one-line install

English how-to for online install.

Uses official Node downloads and the default public package registry.

Mac and Linux: run the shell script in the install folder.
Windows: run the PowerShell script in the same folder.

Steps: Node.js, OpenClaw, optional chat-app plugin, optional China-locale skills, model picker, start scripts, verify.
A China package mirror is not the default.
Piped installs skip the model picker.
Uninstall by deleting the .uclaw folder in your home directory.

This matches the USB Mac installer but downloads components from the network.
